How this list was made
----------------------
The list names the packages whose code is compiled into the extension's JavaScript bundles,
taken from the modules the production build actually emits for the Chrome and Firefox
extensions at the dependency versions pinned in this release; both browsers contain the same
set. Development tools, test libraries and packages that are installed in the source tree but
are not part of the shipped bundle are not listed. Where the same package appears in two
versions, both are listed. The license named for each package is the one it declares; the text
shown under it is the text in the license file the package ships. Where a package ships no
license file, the text is the license published by its authors in their source repository,
and the entry says where.
