# Changesets

The independent `@lingotori/extension` baseline is exactly `0.0.1`. Pending records already included at the baseline snapshot were moved unchanged to [the 0.0.1 archive](../docs/releases/0.0.1/README.md), so they cannot schedule another bump. The baseline is set directly; it intentionally has no additional bump changeset.

Add new changes here for work after that snapshot, using `"@lingotori/extension"` and a conventional commit summary. Run `pnpm exec changeset status` to inspect the next release plan. With no new changesets, the plan is empty. `pnpm release` only creates Git tags; it does not apply changesets or publish browser packages. Tagging, publishing, and merging require their own approval.
